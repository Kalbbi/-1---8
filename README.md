# Вариант 8

## Описание проекта

Прототип веб-приложения с поддержкой удалённого вызова процедур (RPC) на основе протокола TCP.

Проект включает модель данных для сущностей `Member`, `Instruction` и `Output`, интерактивную консоль для работы с моделью, а также клиент и сервер для удалённого вызова процедур.

Данные хранятся в оперативной памяти и не сохраняются на диск.

## Структура проекта

- `src/model.py` — модель данных.
- `src/repl.py` — интерактивная консоль для работы с моделью.
- `src/protocol.py` — протокол обмена данными.
- `src/client.py` — клиент RPC.
- `src/server.py` — сервер RPC.
- `tests/` — тесты модели данных и RPC.
- `run.sh` — скрипт запуска проекта.

## Запуск проекта

Для запуска в среде с поддержкой Bash выполните:

```bash
./run.sh
```

Для запуска интерактивной консоли модели данных из корня проекта выполните:

```bash
python -m src.repl
```

## Команды интерактивной консоли

- `create_member` — создание участника.
- `get_all_members` — получение всех участников.
- `get_member` — получение участника по идентификатору.
- `edit_member` — редактирование участника.
- `create_instruction` — создание инструкции.
- `get_all_instructions` — получение всех инструкций.
- `get_instruction` — получение инструкции по идентификатору.
- `edit_instruction` — редактирование инструкции.
- `create_output` — создание результата.
- `get_all_outputs` — получение всех результатов.
- `get_output` — получение результата по идентификатору.
- `edit_output` — редактирование результата.
- `recent` — получение описаний инструкций и user-agent за последние 9 минут.
- `help` — вывод списка команд.
- `exit` — выход из консоли.

## Тестирование

Для запуска тестов с использованием pytest выполните:

```bash
python -m pytest
```

python -m coverage run -m pytest

## Пример использования

Запустите интерактивную консоль:

```bash
python -m src.repl
```

Создайте участника:

```text
>>> create_member
uid: 1
time: 1791887089
platform: web
user_agent: Mozilla/5.0
```

Создайте связанную с ним инструкцию:

```text
>>> create_instruction
uid: 1
time: 1791887089
input: test input
member: 1
description: test instruction
tags: test
status: new
started: 0
```

Получите инструкцию по идентификатору:

```text
>>> get_instruction
uid: 1
```

Для проверки обработки ошибок повторите создание инструкции с уже существующим `uid = 1`. Программа должна сообщить, что инструкция с таким идентификатором уже существует.

Для проверки редактирования выполните команду `edit_instruction`, указав существующий идентификатор, новый статус и новое описание.
